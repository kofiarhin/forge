# Forge

Forge is an AI-powered software organization that transforms approved ideas into production-ready software through specialized AI teams coordinated by Zoro.

## Product Authority

- [Forge MVP PRD](docs/forge-mvp-prd.md) — approved product requirements and lifecycle authority

## Current Phase

The MVP PRD is approved. Source-code implementation remains gated until the required module contracts, Context API data model, evidence and transition schemas, agent authority boundaries, and first demonstration specification are approved and their implementation tasks are marked `ready`.

## Governing Principles

- Human approval before implementation
- Only `ready` tasks may execute
- Independent Reviewer and QA verification
- Auditable evidence for every transition
- Stop-on-failure workflows
- No Builder self-approval or self-merge
